# Tool icon sources

The selected brand SVGs are generated by `scripts/generate-tool-icons.mjs` and served locally. No third-party asset host is required while viewing the page.

- SVG Logos by Gil Barbara, via `@iconify-json/logos` 1.2.15: https://github.com/gilbarbara/logos — CC0.
- Simple Icons 16.33.0: https://github.com/simple-icons/simple-icons — CC0.
- Functional symbols (Canva, CapCut, live chat systems, help desk platforms and public records websites) use the existing Lucide icon collection. These are descriptive symbols, not reproduced brand logos.

Google Sheets and Docs retain separate symbols inside their shared badge. Microsoft Office uses the Microsoft brand symbol alongside the complete suite label. Brand marks identify the tools listed by the RealeCall team.
